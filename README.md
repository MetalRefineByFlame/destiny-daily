# 五术日课 · destiny-daily

基于**八字 / 奇门遁甲 / 大六壬 / 梅花易数 / 六爻**五门并行推演的每日运势系统。
本地运行、数据私有，每天 08:00 自动生成报告并推送到邮箱。

---

## 一、本命盘（本地查看，不入库）

本项目是公开仓库，**出生数据不进 Git**。排盘结果只在本地生成：

```bash
python scripts/make_profile.py --force    # 从环境变量生成 data/profile.json
python scripts/show_chart.py              # 打印四柱、强弱、格局、用神、起运与大运
```

自己的命盘简评可写在 `docs/我的命盘.local.md`（该文件名已被 gitignore）。

排盘口径（任何人可自行核对）：

- 真太阳时校正（默认东经 120.00°，可用出生地经度覆盖）
- 年柱按**立春**分界，月柱按**节**（非气）分界
- 起运按「三天折一岁」，阳男阴女顺排、阴男阳女逆排
- 强弱用对称通根计分 + 旺相休囚死 + 十二长生加权，非简单数五行个数

> 修改引擎后务必先跑 `python verify.py`（27 项回归，含 1949/2000/2024 三个日柱绝对锚点）。

| 术数 | 实现深度 | 日课中的角色 |
|---|---|---|
| **八字** | 四柱、藏干通根、十神、纳音、十二长生、神煞、大运起运（三天折一岁）、流年流日 | 判断当日干支与本命的生克刑冲合害 → 基础吉凶 |
| **奇门遁甲** | 时家阴阳遁、三元九局（接气法）、地盘三奇六仪、值符值使、天盘九星、八门、八神、门迫空亡 | 给出**吉方、吉时、规避方位** |
| **大六壬** | 月将过宫、天地盘、四课、九宗门定三传（贼克/比用/遥克/昴星/八专/伏吟/返吟）、十二天将、六亲 | 判断**事之成败与外应** |
| **梅花易数** | 农历年月日时起卦、体用互变、旺衰 | 给出**当日整体意象与体用关系** |

## 二之二、每日一卦（独立于五门之外）

在「本命提要」之后单列一栏，**不计入五门加权总分**——它是一面镜子，不是打分器。

**起卦**：蓍草法（大衍之数五十，其用四十有九），三变成一爻，十八变成六爻；
左右两堆各以四揲之，归奇于扐，得 6 老阴 / 7 少阳 / 8 少阴 / 9 老阳。
随机数种子 = `日期 + 农历 + 日干支 + 本命标识`，故**同日同人必得同一卦**，换日则变。
起卦概率严格合于古典：老阴 1/16、少阳 5/16、少阴 7/16、老阳 3/16（已 20 万次实测校验）。

**占断**：依朱熹《易学启蒙》成法，按动爻多寡分七种取辞——

| 动爻 | 断法 |
|---|---|
| 0（六爻皆静） | 本卦**卦辞** |
| 1 | 该动爻**爻辞** |
| 2 | 上方动爻爻辞为主，下方者参之 |
| 3 | 本卦、之卦卦辞**合参**，以本卦为主 |
| 4 | 之卦两个静爻中**居下者** |
| 5 | 之卦**唯一静爻** |
| 6 | 乾坤取**用九 / 用六**，余取之卦卦辞 |

**栏目内容**：

- 卦符、卦名、文王卦序、上下卦及其五行
- 六爻爻图（自上而下，动爻以朱红标出），附每爻**是否得位**（阳居阳位、阴居阴位）
- 卦辞 + 白话；大象传 + 体会
- 之卦（走向）／互卦（内在过程）／错卦（换立场）／综卦（反过来看）
- 卦与本命的呼应：上下卦五行对日主、对用神的关系
- 核心义理、**今日之用**（落到事业 / 人际 / 财务 / 身心）
- **爻位通则**：初爻慎始、二爻得中、三爻多凶、四爻近君、五爻尊位、上爻知止

数据源 `engine/gua64_data.py` 为六十四卦完整经文（卦辞、大象传、三百八十四爻爻辞、
白话、义理、日用），运算在 `engine/zhouyi.py`。

## 二之三、新增板块的取象依据

### 事业（三条业务线）

江公子的业务按十神拆成三条线，每日由流日十神决定哪条是主线：

| 业务 | 十神 | 含义 |
|---|---|---|
| 帮客户优化运营、提升业绩 | 食伤 | 我生者 = 技术输出、方案、表达 |
| 资产配置建议 | 财星 | 我克者 = 财与资源掌控 |
| 办理银行贷款 | 官杀 | 克我者 = 官方、机构、审批 |

再叠加六爻官鬼爻（银行/机构动静）、妻财爻（款项流动）、奇门开门（事业门）与生门（财门）、
六壬初传天将与课体（伏吟/返吟主流程反复）。

### 人际（六亲分论）

按《渊海子平》六亲歌取象：**生我父母印绶，我生子孙食伤，克我官鬼，我克妻财，同我比劫**。

| 关系 | 所主十神 |
|---|---|
| 父母 | 正印 / 偏印 |
| 子女 | 食神 / 伤官 |
| 爱人 | 正财 |
| 同事 | 比肩 / 劫财 |
| 客户 | 正财 / 偏财 |
| 朋友 | 比肩 / 劫财 |

每日把「当日十神的五行」与「该六亲所主十神的五行」做生克比较，得出
比和 / 我生彼 / 彼生我 / 我克彼 / 彼克我 / 当值 六种状态，再给出具体做法。
当日十神若正是该宫之星，则标记为**当值**（该宫事务最集中）。

> 若要进一步个性化，可在 `profile.json` 的 `family.members` 补上各成员的生肖或出生年份。

### 彩票（可建议不买 · 每日至多一种）

**彩气分**以五门加权总分为主锚（权重 0.62），流日十神的财气修正为辅（0.38）：

```
彩气 = 五门总分 × 0.62 + (50 + 十神修正) × 0.38
十神修正：偏财 +18 / 正财 +12 / 食神 +5 / 伤官 +3 / 劫财 −4
          正偏印 −6 / 正官 −12 / 七杀 −14
```

**决策规则**（`lottery_skip_threshold`，默认 50）：

1. 彩气 **< 50** → **今日不建议购买任何彩种**，不出号码
2. 彩气 **≥ 50** → 同一天**只推一个彩种**：
   - ≥ 64 且当日有大盘彩种开奖 → 取双色球/大乐透（搏高奖池需气盛）
   - 否则 → 取快乐8（每日开奖、玩法灵活、单注可控）
3. 开奖日硬规则：双色球 **周二/四/日**，大乐透 **周一/三/六**，快乐8 **每日**

实测 30 天：**18 天不建议购买（60%）**，快乐8 9 天，大盘彩种 3 天。

号码由当日盘面数源加权生成，**不是随机数**：
日干支数 / 农历月日 / 奇门最优时辰的吉宫 / 六壬三传地支 / 梅花本卦上下卦先天数 / 用神河图数。
再按「河图五行配数」（1,6水 2,7火 3,8木 4,9金 5,0土）给候选号加权——用神加码、忌神减码，
最后用「日期 + 数源」作固定种子抽取，保证同一天多次运行号码一致。

⚠ 中奖概率与机选**完全相同**。这一栏真正的价值是**限额纪律**——
把「今天不买」变成一个有依据的决定，而不是靠手气冲动。月度预算 ¥100、单日上限 ¥5。

### BTC 复盘

数据源 `data-api.binance.vision`（币安公开镜像，无需 Key）。主站与 CoinGecko/OKX 在部分网络下不可达。

只做**客观技术面描述**：现价、24h 变动与振幅、MA7/MA30/MA60 排列与相对位置、30 日年化波动率。
**不给目标价、不做点位预测**。术数视角单独成行，并明确标注与技术面互不印证。

联网失败时优雅降级（返回 `ok=False`，报告注明「行情未取到」，其余板块照常生成）——
每日定时任务不该因行情接口抖动而中断。结果在进程内缓存 5 分钟，避免批量生成时 N 天 = 2N 次请求。

## 三、用法

```bash
# 生成今天
python daily_run.py

# 指定某天
python daily_run.py 2026-10-01

# 连续生成 7 天（预览未来走势）
python daily_run.py 2026-10-01 --days 7

# 只在终端看摘要，不落盘
python daily_run.py --text
```

产出在 `output/`，一次三份：

| 文件 | 用途 | 排版方式 |
|---|---|---|
| `destiny-YYYY-MM-DD.html` | 完整报告，浏览器看 / 打印 / 存档 | grid + flex，宣纸风，最好看 |
| `destiny-YYYY-MM-DD.mail.html` | **邮件正文**，发到邮箱的就是它 | table 布局 + 全内联样式 |
| `destiny-YYYY-MM-DD.txt` | 纯文本摘要，邮件降级正文 / 终端看 | 无排版 |

> 为什么要两份 HTML：浏览器那份用了 grid / flex / CSS 变量 / 伪元素，
> QQ 邮箱、163、Outlook（Word 排版引擎）会把它剥掉或渲染错乱，Gmail 也在投毒黑名单里。
> 邮件只能退回「table + 全内联」的老写法，详见 `engine/mail_report.py` 顶部注释。

邮件结构：

```
multipart/mixed
  └─ multipart/alternative
       ├─ text/plain      纯文本摘要（不支持 HTML 时显示这个）
       └─ text/html       排版版正文 ← 主流客户端显示这个
  └─ attachment: *.html   完整版附件，留档 / 转发用
```

## 六、关于评分（重要）

五门各自的评分体系量纲不同，直接加权会让结果挤在一起且偏悲观（实测 μ≈49 σ≈8）。
因此做了**分布标定**：各门先按 150 天采样得到的 μ/σ 做 z-score 标准化，再加权合成总分。

标定后：总分 μ≈50、σ≈13，等级分布约为
上吉 2% / 吉 12% / 平顺 37% / 宜守 20% / 低调 26%。

**含义**：分数是「相对于你自身长期分布」的位置，不是一个绝对吉凶值。
60 分不代表今天一定顺利，只代表在今天这个样本里偏上。
